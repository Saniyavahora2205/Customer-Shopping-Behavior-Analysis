# Customer Shopping Behavior Dataset

This dataset captures detailed information about customer demographics, shopping patterns, and purchase behavior.  
It is designed for data analysis, visualization, and machine learning projects focused on consumer insights.

## 📊 Features
- **Customer Demographics**: Age, Gender, Location
- **Shopping Behavior**: Frequency of visits, Product categories purchased
- **Purchase Details**: Number of purchases, Payment methods
- **Geographic Data**: City, Latitude, Longitude for location-based analysis

## 🎯 Use Cases
- Build interactive dashboards in Power BI or Tableau
- Perform customer segmentation and clustering
- Analyze purchase trends across demographics and regions
- Train ML models for predicting customer behavior

## 📂 File Information
- Format: CSV
- Rows: [Number of records]
- Columns: Age, Gender, Location, Product Category, Purchase Count, Payment Method, Latitude, Longitude

## 🚀 Applications
- Retail analytics
- E-commerce insights
- Marketing strategy optimization
- Academic projects in data science
